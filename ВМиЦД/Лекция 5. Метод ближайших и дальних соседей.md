## Метод ближайших соседей
### 1. Выбираем точки

|     | A   | B   | C   | D   | K   | E   | F   | L   |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| x   | 1   | 2   | 3   | 2   | 4   | 5   | -1  | -2  |
| y   | -1  | -3  | 0   | 1   | 4   | 1   | 1   | -1  |

### 2. Находим матрицу расстояний

|     | A   | B    | C    | D    | K     | E    | F    | L    |
| --- | --- | ---- | ---- | ---- | ----- | ---- | ---- | ---- |
| A   | *0* | 2.24 | 2.24 | 2.24 | 5.9   | 4.5  | 2.82 | 3    |
| B   |     | *0*  | 3.16 | 4    | 7.8   | 5    | 5    | 4.47 |
| C   | тут |      | *0*  | 1.41 | 4.1   | 2.21 | 4.1  | 5.1  |
| D   |     | все  |      | *0*  | 3.6   | 3    | 3    | 4.2  |
| K   |     |      | си-  |      | *0*   | 3.16 | 5.83 | 7.82 |
| E   |     |      |      | -ме- |       | *0*  | 6.32 | 7    |
| F   |     |      |      |      | -три- |      | *0*  | 2.24 |
| L   |     |      |      |      |       | -чно |      | *0*  |

### 3. Берем самое маленькое расстояние (СD)
Это первый кластер

### 4. Переписываем таблицу без CD

|     | CD  | A   | B    | K   | E   | F    | L    |
| --- | --- | --- | ---- | --- | --- | ---- | ---- |
| CD  | *0* |     |      |     |     |      |      |
| A   |     | *0* | 2.24 | 5.9 | 4.5 | 2.82 | 3    |
| B   |     |     | *0*  | 7.8 | 5   | 5    | 4.47 |
| K   |     |     |      | *0* | 3.2 | 5.83 | 7.82 |
| E   |     |     |      |     | *0* | 6.3  | 7    |
| F   |     |     |      |     |     | *0*  | 2.24 |
| L   |     |     |      |     |     |      | *0*  |

### 5. Берем ближайшее расстояние до C или D и записываем

|     | CD  | A        | B        | K       | E        | F     | L       |
| --- | --- | -------- | -------- | ------- | -------- | ----- | ------- |
| CD  | *0* | **2.24** | **3.16** | **3.6** | **2.24** | **3** | **4.2** |
| A   |     | *0*      | 2.24     | 5.9     | 4.5      | 2.82  | 3       |
| B   |     |          | *0*      | 7.8     | 5        | 5     | 4.47    |
| K   |     |          |          | *0*     | 3.2      | 5.83  | 7.82    |
| E   |     |          |          |         | *0*      | 6.3   | 7       |
| F   |     |          |          |         |          | *0*   | 2.24    |
| L   |     |          |          |         |          |       | *0*     |

### 6. Берем самое маленькое расстояние
Точки A, B, С, D, E образуют кластер.


### 7. Переписываем таблицу без ABCDE

Для FL и ABCDE считаем минимальное расстояние от F до ABCDE - 2.82.
Для L и ABCDE минимальное расстояние равно 3.
Из них минимальное 2.82.

|       | ABCDE | FL   | K    |
| ----- | ----- | ---- | ---- |
| ABCDE | *0*   | 2.82 | 3.2  |
| FL    |       | *0*  | 5.83 |
| K     |       |      | *0*  |

### 8. Составляем таблицу для ABCDEFL и K

|       | ABCDE | K   |
| ----- | ----- | --- |
| ABCDE | *0*   | 3.2 |
| K     |       | *0* |
