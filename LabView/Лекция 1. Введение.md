# Лекция 1. Введение
- Получать информацию с датчиков
- Обрабатывать полученные сигналы
- На основании данных управлять различными компонентами

## Основные панели
#### Лицевая панель (в клеточку)
>То, что видит оператор

- Controls -> ввод
- Indicators -> результат

#### Блок-диаграмма (белая)
>Что выполняет программа

- Терминалы
- Функции
- Проводники
- Структуры

## Навигация
#### Правила ориентации
- Front Panel -> Controls
- Block Diagram -> Functions (VI и функции)

#### Controls
>Автоматически создается терминал на Block Diagram

- Элементы ввода
- Индикаторы

#### Functions
>Здесь строится алгоритм

- Функции и VI для вычислений
- Константы, структуры

#### Context Help
>Показывает информацию по объекту

### Горячие клавиши
- Ctrl + H открывает Context Help
- f1 для подробной справки
- Ctrl + E переключение между Front Panel и block Diagram
- ПКМ на Front Panel открывает Controls
- ПКМ на Block Diagram  открывает Functions
- 2 клика по Control / Indicator для перехода к соответствующему терминалу

### Входы и выходы
- Control - ввод данных
- Indicator - вывод данных

### Как читать блок диаграмму
1. Найти все взоды
2. Затем операции
3. Затем выходы

## Пример программы
1. Создать новый VI
2. На Front Panel задать Расстояние, Предел, Индикатор
3. На Block Diagram найти функцию сравнения
4. Соединить проводами
5. Запустить
