# Лекция 6. PostgreSQL. Основы SQL
### Особенности синтаксиса
- `;` означает конец запроса
- `--` для однострочных комментариев
- `''` для строк
- `""` только для названий столбцов
- Числа без кавычек

## SELECT
Базовый запрос для извлечения информации.

Структура запроса:

```sql
SELECT {column1, column2} FROM {table_name};
```

Пример:

```sql
SELECT * FROM products;
```

`SELECT *` вернет все столбцы. Желательно не писать `*`, а перечислять те столбцы, которые действительно нужны.

### LIMIT 
Позволяет ограничить число строк в выдаче.

```sql
SELECT * FROM orders LIMIT 10;
```

### AS
Позволяет создавать псевдонимы.

```sql
SELECT 
name AS "Product name" 
FROM orders
LIMIT 10;
```

### Вычисляемый столбец
```sql
SELECT 
name, 
weight_g / 1000 AS weight_kg
FROM products;
```

### WHERE
Определяет, какие строки оставить.

```sql
SELECT product_id, name, price
FROM products
WHERE price > 5000 AND weight_g < 1000
```

#### Операторы сравнения
- `=` равно
- `<>` или `!=` не равно

#### Приоритет
1. `NOT`
2. `AND`
3. `OR`

Для разделения условий можно использовать круглые скобки.

#### BETWEEN
Для диапазонов.

```sql
SELECT product_id, name, prict
FROM products
WHERE price BETWEEN 3000 AND 7000;
```

#### IN
Для проверки вхождения в ряд категорий.

```sql
SELECT order_id, status
FROM orders
WHERE status IN ('ready', 'processing');
```

#### LIKE
Для поиска по шаблону
- `%` для пропуска любого количества символов
- `_` для пропуска ровно 1 символа

Есть и регулярные выражения.

```sql
SELECT product_id, name, sku
FROM products
WHERE sku LIKE 'SKU%'
```

В PostgreSQL `LIKE` учитывает регистр. Чтобы он не учитывался нужно использовать `ILIKE`.

Для отрицания шаблона используется `NOT`

```sql
SELECT product_id, name
FROM products
WHERE name NOT LIKE '%чайник%'
```

### DISTINCT
Оставит только уникальные значения.

```sql
SELECT DISTINCT city
FROM customers;
```

### ORDER BY
Для сортировки выходных значений. Пишется в конце запроса.

```sql
SELECT DISTINCT city
FROM customers
ORDER BY city -- от А до Я;
```

Изначально сортировка по возрастанию (`ASC`). Можно поменять на `DESC`.

```sql
SELECT DISTINCT first_name, city
FROM customers
ORDER BY 2 DESC, 1
```

Сперва сортировка по `city`, и потом внутри города по `first_name`.

#### NULLS FIRST и NULLS LAST
В дополнение в `ASC` и `DESC` для работы с `NULL`.

```sql
SELECT * FROM couriers
ORDER BY rating DESC
```

Так все `NULL` будут в начале. Можно убрать их в конец таким способом

```sql
SELECT * FROM couriers
ORDER BY rating NULLS FIRST
```

### OFFSET
Пропускает указанное число строк.

```sql
SELECT * 
FROM orders 
LIMIT 10
OFFSET 20;
```

### COALESCE
Возвращает первое значение, которое не `NULL`.

```sql
SELECT customer_id, last_name, first_name
COALESCE(middle_name, 'не указано') AS middle_name_display
FROM customers
ORDER BY customer_id
LIMIT 10;
```

### CASE
Позволяет вычислить категорию по условию.

```sql
SELECT product_id, name, price
CASE
	WHEN price < 2000 THEN 'До 2000'
	WHEN price <= 5000 THEN 'От 2000 до 5000'
	ELSE 'Свыше 5000'
END AS price_group
FROM products
```

## NULL
Означает отсутствие значения. Это не пустая строка и не 0. С `NULL` нельзя сравнивать. Результатом сравнения будет `UNKNOWN`. Проверить значение на `NULL` можно с помощью `IS NULL` и `IS NOT NULL`.

```sql
SELECT * FROM couriers
WHERE rating < 4 OR rating IS NULL;
```

## Порядок обработки запроса
Для запроса вида SELECT -> FROM -> WHERE -> ORDER BY порядок обработки будет следующим
1. FROM
2. SELECT
3. WHERE
4. ORDER BY

Поэтому столбцы переименованные в SELECT не получится использовать в WHERE.

## Примеры
Вывести идентификатор, имя, цену и вес в килограммах 5 самых дорогих товаров.

```sql
SELECT 
pruduct_id, name, price, 
weight_g / 1000 AS weight_kg
FROM procuts
WHERE weight IS NOT NULL AND weight_g <= 1000
ORDER BY price DESC
LIMIT 5
complete```


Получить различные виды транспорта курьеров

```sql
SELECT DISTINCT vehicle
FROM couriers
```

Найти курьеров без рейтинга

```sql
SELECT *
FROM couriers
WHERE rating IS NULL
```

Вывести 10 последних оформленных заказов

```sql
SELECT *
FROM orders
ORDER BY purchased_at DESC
LIMIT 10
```

Получить 5 самых дорогих доставок и известной стоимостью

```sql
SELECT *
FROM deliveries
WHERE cost IS NOT NULL
ORDER BY cost DESC
LIMIT 5;
```
