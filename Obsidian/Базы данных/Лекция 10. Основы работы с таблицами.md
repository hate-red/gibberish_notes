# Лекция 10. Основы работы с таблицами
## Создание таблиц
Для логического разделения таблиц внутри одной базы их (таблицы) можно разбить на блоки с помощью схем (`CREATE SCHEMA shop`). Внутри одной схемы данные уникальны, т.е. разные схемы могут иметь таблицы с одинаковым названием. Для определения из какой схемы брать таблицу пишут `schema_name.table_name`. По умолчанию в базе есть 1 схема `public`.

При создании таблицы можно накладывать ограничения как на отдельные столбцы, так и на всю таблицу.

```sql
CREATE TABLE shop.category (
	category_id BIGINT
		GENERATED ALWAYS AS IDENTITY
		PRIMARY KEY,
	name TEXT NOT NULL,
	CONTRTRAINT category_name_unique
		UNIQUE(name)
)
```

Можно писать просто `name TEXT NOT NULL UNIQUE`. Тогда СУБД сама создаст имя ограничению. Для того чтобы поменять ограничение нужно знать его имя. Поэтому некоторые люди задают его сами.

## Заполнение данными
Первыми создаются родительские таблицы (те, что без зависимостей от других таблиц). Например, сперва категория, потом товар.

```sql
INSERT INTO shop.category (name)
VALUES
('name1'),
('name2'),
('name3');
```
`INSERT`, `CREATE`, `DELETE`, `UPDATE` возвращают только количество измененных строк. Можно вернуть данные через `RETURNING`.

```sql
INSERT INTO shop.category (name)
VALUES
('name1'),
('name2'),
('name3')
RETURNING category_id, name;
```
В `INSERT` можно использовать подзапросы (например, чтобы узнать id категории).

## Изменение данных
Все `INSERT`, `CREATE`, `DELETE`, `UPDATE` выполняются как транзакции.


```sql
UPDATE cetegory
SET name='name_1'
WHERE category_id=3;
```
Если не указать WHERE новые значения изменят все данные в таблице.

## Удаление данных

```sql
DELETE FROM category
WHERE name='name_1'
```

Так можно удалить категорию без товаров. Но если есть товары с этой категорией, то удалить ее не получится.

Если при удалении категории должны удалится все товары в ней, то ограничение на должно быть `ON DELETE CASCADE`.

Варианты ограничений:
- `NO ACTION`
- `RESTRICT`
- `CASCADE`
- `SET NULL`

Эти правила работают еще и на `UPDATE`, т.е. при изменении первичного ключа его можно изменить во всех таблицах.

Помимо `DELETE` есть `TRUNCATE`

```sql
TRUNCATE TABLE category;
```
## Изменение структуры таблицы

```sql
ALTER TABLE shop.product
ADD COLUMN weight_g INTEGER NOT NULL;
```
У `ALTER` много применений (добавить, изменить, переименовать столбец, добавить ограничение и т.д.).
