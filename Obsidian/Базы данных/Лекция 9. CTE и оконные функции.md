# Лекция 9. CTE и оконные функции
## CTE
CTE (Common Table Expression)- именованный подзапрос.

```sql
WITH {name} AS ({sub_query}) {main_query}
```

Если назвать таблицу в `WITH` именем уже существующей таблицы, то в рамках запроса таблица бд с этим именем будет недоступна.

## Оконная функция
Идея в том, чтобы получить новые значения, не схлопывая строчки (как при агрегатных функциях). 

### Пример

```sql
SELECT product_id, category, price,
AVG(price) OVER(PARTITION BY category) AS category_avg
FROM products;
```

### Анатомия OVER

```sql
функция(аргементы) OVER (
	PARTITION BY столбцы -- на какие разделы поделить
	ORDER BY столбцы -- в каком порядке идут строки в разделе
	рамка -- какие строки раздела видит функция
)
```

- Все 3 части необязательны
- `OVER()` означает, что окно - вся таблица (как `HAVING` без `GROUP BY`)
- Без `OVER` функция не оконная

### PARTITION BY
Делит строки на независимые разделы.

- Внутри раздела оконная функция считает отдельно
- Строки других разделов она не видит
- На границе разделов счетчики и накопления начинаются заново

### Порядок выполнения окон
1. `FROM`
2. `WHERE`
3. `GROUP BY`
4. `HAVING`
5. Windows (оконные функции)

### Окна и WHERE
Окно нельзя писать в `WHERE`.

Неверно:

```sql
SELECT name, price, RANK() OVER(ORDER BY price DESC) AS r
FROM products WHERE r <= 3; -- окна еще нет
```

Верно:

```sql
WITH t AS (
	SELECT name, price, RANK() OVER(ORDER BY price DESC) AS r
	FROM products
)
SELECT * FROM t WHERE r <= 3;
```

Так мы сперва считаем окно в CTE, а потом фильтруем.

### Что выбрать?

| Способ                    | Сохраняет строки | Как считает                 | Когда выбирать                                |
| ------------------------- | ---------------- | --------------------------- | --------------------------------------------- |
| Группировка               | Нет              | Одна раз на группу          | Нужны только итоги                            |
| Коррелированный подзапрос | Да               | Логически для каждой строки | Простые случаи, одно значение                 |
| Оконная функция           | Да               | Один раз на раздел          | Итог рядом с деталями, ранги, соседние строки |

### Окно поверх GROUP BY

```sql
SELECT status, COUNT(*) AS cnt,
ROUND(100.0 * COUNT(*) / SUM(COUNT(*)) OVER(), 1) AS pct
FROM orders GROUP BY status;
```

1. Сначала `GROUP BY` собирает группы, `COUNT(*)` считает размер каждой
2. Затем окно `SUM` суммирует эти значения по всем группам

### Три семейства оконных функций

| Семейство           | Функции                                                                  | Что делают                                   |
| ------------------- | ------------------------------------------------------------------------ | -------------------------------------------- |
| Ранжирующее         | `ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `PERCENT_RANK`, `CUME_DIST` | Нумеруют строки и определяют их положение    |
| Смещения и значения | `LAG`, `LEAD`, `FIRST_VALUE`, `LAST_VALUE`, `NTH_VALUE`                  | Берут значения из соседних или крайних строк |
| Агрегатные          | `SUM`, `AVG`, `COUNT`, `MIN`, `MAX`, `OVER`                              | Считают итоги по окну                        |

## Ранжирование
==🟣Ранжирование== - присвоение каждой строке номера по заданному порядку сортировки.

- Первое место получает самая "лучшая" строка по `ORDER BY`
- Номер добавляется как новый, строки остаются на месте
- Нумерацию можно вести отдельно в каждой группе

### Топ n в каждой группе

```sql
WITH ranked AS (
	SELECT name, category, price, DENSE_RANK() OVER(
		PARTITION BY category ORDER BY price DESC
	) AS rnk
	FROM products
)
SELECT * FROM ranked WHERE rnk <= 2 ORDER BY category, rnk, name;
```

### Что выбрать для топ-N?

| Вопрос бизнеса                                            | Функция    | Почему                        |
| --------------------------------------------------------- | ---------- | ----------------------------- |
| Ровно N строк в группе                                    | ROW_NUMBER | Номера уникальны              |
| Все, кто вошел в первые N мест, с пропусками после ничьих | RANK       | Ничья занимает несколько мест |
| Все товары с N самыми высокими уровнями цены              | DENSE_RANK | Ранги идут подряд             |

### NTILE
`NTILE(n)` делит упорядоченные строки на `n` примерно равных корзин и нумерует их от 1 до `n`.

```sql
NTILE(3) OVER (ORDER BY price, product_id)
```

### PERCENT_RANK и CUME_DIST
- `PERCENT_RANK = (ранг - 1) / (число строк - 1)`
- `CUME_DIST` - доля строк, значение которых не больше текущего
