# Лекция 5. Нормализация (продолжение)
## Задача
### Условие
- Есть фирма, занимается предоставлением услуг. 
- На фирме работают сотрудники. 
- У них есть номер (сотрудника), ФИО и должность. 
- Сотрудники распределены по нескольким отделам. 
- Наша компания работает с предприятиями-клиентами. 
- Каждое предприятие имеет название и адрес. 
- С предприятием может быть заключено несколько договоров. 
- Каждый договор характеризуется уникальным номером, датой и типом. 
- Каждый договор курирует некоторый сотрудник. 
- По договору выставляются счета на оплату. 
- У счета есть уникальный номер, дата выставления, срок оплаты и сумма. 
- Счет может быть оплачен в несколько приемов. 
- Каждый платеж характеризуется номером, датой и суммой. 
- Номер платежа уникален в пределах его счета. 
- Если счет вовремя не оплачен, то формируется пенни.

### Что сделать?
Необходимо создать реляционную модель, отвечающую требованиям 3НФ.
### Решение
#### Сущности
1. **Работник** (*id*, ФИО, id должности)
2. **Должность работника** (*id*, название)
3. **Отдел** (*id*, название)
4. **Клиент** (*id*, название, адрес)
5. **Услуга** (*id*, стоимость)
6. **Договор** (*id*, дата, id клиента, id типа договора, пенни)
7. **Договор-услуга** (*id договора*, *id услуги*, количество)
8. **Тип договора** (*id*, название)
9. **Счет** (*id*, дата, срок, сумма, id договора)
10. **Платеж** (*id счета*, *номер платежа*, сумма, дата)
