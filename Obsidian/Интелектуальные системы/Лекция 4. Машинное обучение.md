# Лекция 4. Машинное обучение
==Машинное обучение (ML)== - алгоритмы и технологии, позволяющие компьютеру автоматические решать конкретные задачи основываясь на накопленном опыте без вмешательства человека.

### Процесс ML
1. Определение проблемы
2. Исследование данных
3. Подготовка данных
4. Моделирование
5. Оценка
6. Внедрение

==Целевая переменная== - правильный ответ, которому должен соответствовать результат работы модели.

### Типы ML
1. Обучение с учителем (входные данные + метки)
2. Обучение без учителя (только входные данные)
3. Обучение с подкреплением (данные о действиях агента в интерактивной среде)


### Сравнение подходов

|                                 | С учителем                                 | Без учителя                                          |
| ------------------------------- | ------------------------------------------ | ---------------------------------------------------- |
| **Цели**                        | Спрогнозировать результат для новых данных | Получить ценную информацию из большого объема данных |
| **Входные данные**              | Размеченные данные                         | Не размеченные данные                                |
| **Сложность**                   | Простой метод                              | Сложное с точки зрения вычислений                    |
| **Обучение в реальном времени** | Надежный подход                            | Надежность хуже                                      |
| **Точность результатов**        | Высокая точность                           | Менее точный подход                                  |
| **Недостатки**                  | Метки требуют дополнительную проверку      | Результат необходимо дополнительно проверять         |
