# Лекция 1. Экспертные системы

==Экспертная система (ЭС)== - система, которая частично заменяет эксперта в определенной области.

Система принимает решения на основе правил и данных из базы знаний. Разрабатывается такая база совместно с экспертом и дает представление о поведении эксперта.

### Структура ЭС
1. Интерфейс
2. Пользователь
3. Радактор базы знаний
4. Эксперт
5. Инженер по знаниям
6. Рабочая память
7. База знаний
8. Решатель (механизм логического вывода (МЛД))
9. Подсистема объяснений (reasoning, графы принятия решений)

Интелектуальные системы
1. Статические (база знаний не меняется)
2. Динамеческие (база знаний обновляется)

База данных специализирована для сохранения исходных и промежуточных данных.

База знаний специализирована для сохранения долговременных данных, обрисовывающих рассметриваемую область

Решатель применяя исходные данные из рабочей памяти и БЗ формирует последовательность правил.

Компонент приобретения знаний автоматизирует процесс заполения ЭС знаниями

Объяснительный компонент упрощает эксперту построение системы, а для пользователя предоставляет путь, по которому системма пришла к заключению.

Диалоговый компонент нацелен на упрощение процесса решения пользователем задачи.

В архитектуре динамической ЭС добавляется подсистема связи с внешним окружением. База знаний и машина вывода при этом могут значительно изменится, чтобы отобразить временнУю логику происходящих событий.
