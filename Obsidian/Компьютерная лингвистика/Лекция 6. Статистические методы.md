# Лекция 6. Статистические методы
Используются для извлечения количественных характеристик текстов ЕЯ, работы с большими массивами текстов, реализиции предсказаний или вывода (инференса).

### Недостатки
- Требуется много данных, в том числе размеченных
- Слабая предсказуемость результатов обучения
- Слабая интерпретируемость результатов инференса
- Сложность автоматической оценки результата

### Достоинства
- Решает сложные современные задачи КЛ в большинстве случаев лучше, чем методы на правилах
- Выявляет скрытые корреляции и исследует язык как естественный феномен

### Типы
1. Классические статистические методы (машиннное обучение)
2. Нейросетевые методы (глубокое обучение)
3. Гибридные методы (нейро-символьные)

### Задача CV в общем виде
Для набора пар вида $(x, y)$ найти такую функцию, которая наилучшим образом предсказывает результат $y$ для новых данных $x$.

Мерой качества (функцией потерь) $C$ является такая функция, которая позволяет получать $y$ близкие к обучающей выборке, при этом генерализирует $y$.

### Меры качества регрессии
- MSE
- MAE
- R2 (Он же коэффициент детерминации)

### Меры качества классификации
- TP (верно предсказан класс)
- TN (верно не предсказан класс)
- FP (неверно предсказан класс - ошибка первого рода)
- FN (неверно не предсказан класс - ошибка второго рода)
- Accuracy
- Precision (прецизионность)
- Recall
- F1-score (F1-мера)

### Практические задачи СМ
#### Частеричная разметка (POS-tagging)
Задача сводится к классификации слов текста по классам частей речи.

- Статистические подходы (HMM)
- Нейросетевые подходы (RNN, LSTM)

#### Извлечение именованных точностей (NER)
Задача сводится к классификации слов текста по классам именованных сущностей.

- Статистические подходы (CRF, HMM)
- Нейросечевые подходы (LSTM, трансформеры (BERT))

#### Извлечение отношений (Relation Extraction)
Задача сводится к классификации пар сущностей по словарю отношений онтологии.

- Статистические подходы (логистическая классификация, SVM)
- Нейросетевые подходы (CNN, GNN)

#### Машинный перевод
Задача сводится к регрессии - генерации нового текста на основе существующего.

- Статистические подходы (фразовые модели, модели n-грамм)
- Нейросетевые подходы (LSTM, трансформеры)

Метрики для оценки: BLEU, ChrF, TER, COMET.

#### Реферирование текста
Та же регрессия. Включает сокращение и упрощение текста.

- Статистические подходы (TL-IDF метод, MMR)
- Нейросетевые подходы (LSTM, трансформеры)

Метрики для оценки: ROUGE, SARI.

#### Вопросно-ответные системы
Задача решается как классификацией, так и регрессией.

- Статистические подходы(TF-IDF, SVM)
- Нейросетевые подходы (BERT, GPT)

#### Распознавание речи
Задача регрессии.

- Статистические подходы (GMM, преобразования Фурье, HMM)
- Нейросетевые подходы (TTS, LSTM, трансформеры)

Метрики для оценки: WER, TER, расстояние Левенштейна

#### Анализ тональноести
Задача классификации.

- Статистические подходы (TF-IDF, логистическая классификация, наивный Байес)
- Нейросетевые подходы (CNN, LSTM, трансформеры)

#### Тематическое моделирование (Topic Modeling)

- Статистические подходы (латентное распределение Дирихле (LDA))
- Нейросетевые подходы (трансформеры (BERTopic))

Метрики для оценки: Perplexity (общая для LLM)

#### Генерация текста
Задача регрессии.

- Статистические подходы (модели Шеннона, HMM)
- Нейросетевые подходы (RNN, трансформеры)

Метрики для оценки: Perplexity, ROUGE.
