# Лекция 3. Проектирование лицевой панели и пользовательского интерфейса

## Элементы управления и индикаторы
### Graph и Chart
- Chart используется чтобы положить данные по одному
- Graph используется для отображения всего массива данных

### Настройки терминала
- Caption отображается только на Front Panel, в отличии от Label
- Желательно писать в разделе Documentation назначение терминала и заполнять Tip strip для подсказки
- Также необходимо уменьшать риск ошибки оператора, например через снижение диапазона значений

### Подписи
Их лучше добавлять. Есть Free Label для группировки интерфейса и комментариев на Block Diagram.

## UI
Терминалы желательно группировать в отдельные логические блоки.
