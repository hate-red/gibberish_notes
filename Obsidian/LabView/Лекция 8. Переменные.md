# Лекция 8. Переменные
## Polling и Events
Цикл постоянно опрашивает состояние элементов. Это просто, но тратит много ресурсов. Для решения этой проблемы можно создать `Event Structure`. 

## Переменные
Позволяют читать и записывать значения без проводников. При одновременной записи есть риск race condition.

Есть локальные и глобальные. Глобальные можно использовать в других приборах, локальные действуют только в рамках текущего прибора.
