1. Генерация идеи \
   Здесь идея превращается в конкретную гипотезу
2. Разработка \
   На этом этапе создается прототип (не путать с MVP)
3. Внедрение \
   Использование инновации, оценка эффективности
4. Коммерциализация \
   Продвижение, поиск каналов сбыла, формирование потребительской базы
5. Масштабирование \
   Выход на другие рынки
