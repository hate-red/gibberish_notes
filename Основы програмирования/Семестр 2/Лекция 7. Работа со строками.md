## Символы
Каждому символу строки соответствует уникальный числовой код из таблицы ASCII. В ней каждый символ занимает 1 байт.

Коды от 0 до 127 интернациональные, от 128 до 255 альтернативные коды национальных алфавитов.

Потом появился Unicode. Это не таблица, а стандарт. Он описывает, какие символьные знаки допустимы и задает им целые числа, а также определяет правила размещения кодовых позиций в памяти (UTF).

- UTF-32 - 4 байта на символ
- UTF-16 - 2 байта на символ
- UTF-8 - 1 байт на символ

UTF-8 обеспечивает наибольшую совместимость с ASCII.

>В C++ есть библиотека cctype для проверки символа на принадлежность определенным категориям:

```c++
// работает для кодов от 0 до 127
isupper(c)
isdigit(c)
```

## Строки с 0 окончанием
*Символьная строка* - последовательность символов, которая заканчивается символом с кодом 0.

>Этот символ обозначается `\0`

Если собирать такую строчку вручную, то компилятор будет много жаловаться (в windows). Чтобы не жаловался, нужно подключить следующий флаг:

```c++
#define _CTR_SECURE_NO_WARNINGS
```

### Создание
```c++
// Можно задать строку так
char str[4] = "abc";

// Или так
char str[] = "abc";

// И еще вот так
char str[]{'a', 'b', 'c', '\0'};

// И даже так
char* s3 = "abc";
```

`strlen()` - длина строки.

### Присвоение
```c++
// Так можно
str[i] = "a";

char str1[] = "abc";
char str2[1000] = "abc";

// Так не получится
str1 = str2;
```

```c++
// Читает до первого пробела / символа перевода строки
cin >> str1;
// Потом в буфере остается мусор и при следующем вводе он будет стоять первым символом

// Читает 10 символов
cin.getline(s, 10);
```

### Операции
1. Сравнение через `==` \
   *Сравниваются указатели*
2. Сравнение через `strcmp` \
   Лексикографическое сравнение
3. Сравнение через `strncmp` \
   Сравнение первых `n` символов
4. Конкатенация через `strcat`
5. Копирование через `strcpy`

>Для использования этих функций надо подключить `cstring`

## Класс std::string
Внутри строка с 0 окончанием. Есть множество методов и перегруженных операторов для выполнения различных действий.

>Для использования этих функций надо подключить `string`
