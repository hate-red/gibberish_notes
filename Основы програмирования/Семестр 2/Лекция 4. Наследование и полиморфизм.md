## Наследование
>Наследование позволяет повторно использовать общую логику и в то же время добавлять новые концепции

### Участники отношения
- **Исходный** *(тот, на основе которого создается другой)* класс называется базовым или родительским.
- **Новый** *(тот, на который создается на базе исходного)* класс называется производным, дочерним или наследником.

>Конструкторы не наследуются, но можно вызвать базовые конструкторы в новом классе:

```c++
public:
	Point3d(float x, float y, float z) :
		Point2d{x, y}, z{z}
```

### Правила
1. Элементы базового класса автоматически создаются у дочернего класса
2. Не наследуются конструкторы (пример выше)
3. Закрытые (private) элементы наследуются, но без доступа напрямую, т.е. через геттеры и сеттеры
4. В дочернем классе можно **добавлять** новые члены, **использовать** методы и атрибуты родительского класса, **переопределять** или изменять его методы

### Переопределение поведения
```c++
class Base
{
public:
	void read()
	{
		...
	}	
};

class Son : public Base
{
	void read()
	{
		// используем поведение базового класса
		read();
		// и добавляем что-то поверх этого
		cout << "что-нибудь еще";
	}
};
```

## Полиморфизм
### Пример
```c++
// Базовый класс
class Gun 
{
	virtual void shoot();
};

// Наследники
class AK47
{
	void shoot() override
	{
		cout << "tra-ta-ta!";
	}
};

class M16
{
	void shoot() override
	{
		cout << "pa-pa-pa!";
	}
};
```

В примере выше у класса Gun метод shoot объявлен как виртуальный (virtual), при этом, метод не определен. Такие классы имеют свое название - абстрактные.

*Абстрактный класс* - класс содержащий хотя бы 1 виртуальную функцию.

Эти методы (виртуальные) затем переопределяются в дочерних классах через override.
