### Статические члены
*Статический член класса* - константа, которая принадлежит не отдельному объекту, а классу в целом.

- Доступен внутри функций классов просто по имени
- Доступен вне класса без ссылки на экземпляр
- Создаются через `static`

```c++
class Foo {
	...
	public:
		void fn() {
			cout << BAR;
		}
		
		static const int BAR = 42;
		
		static int static_fn(){
			return BAR;
		}
	...
};

int main() {
	Foo::BAR // 42
	Foo::static_fn // 42
	return 0;
}
```


```c++
class Foo {
	...
	// если константа в private, то только объявляем
	private:
		static const int BAR;
	...
};

// определяем вне класса
int Foo::BAR = 42;
```
