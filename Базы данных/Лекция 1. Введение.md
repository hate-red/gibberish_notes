# Лекция 1. Введение

Данные - факты информации об объектах, действиях, событиях.

>Данные становятся информацией, когда известен их контекст и смысл.

База данных - организованная совокупность взаимосвязанных данных, предназначенная для длительного хранения, поиска, изменения и совместного использования.

Система управления базами данных (СУБД) - программное обеспечение для создания, хранения, поиска, изменения, защиты и восстановления данных.


### Функции БД
1. Управление структурой
2. Манипулирование данными
3. Контроль целостности
4. Управление транзакциями
5. Управление параллельным доступом
6. Восстановление после сбоев
7. Безопасность и контроль доступа
8. Оптимизация выполнения запросов

Data definition language (DDL) - для работы с таблицами.
Data manipulation language (DML) - для работы с данными таблицы.

Целостность данных - их корректность, согласованность и соответствие правилам предметной области.

Транзакция - логически завершенная последовательность операций, которая должна выполняться полностью или не выполняться вовсе.

#### ACID
1. Atomicity (Атомарность) - Все транзакции выполняются целиком или отменяются целиком
2. Consistency (Согласованность) - Данные переходят из одного корректного состояния в другое
3. Isolation (Изоляция) - Параллельные транзакции не нарушают работу друг друга
4. Durability (Долговечность) - После COMMIT результат не теряется при сбое

Write ahead log (журнал предзаписи) - механизм защиты от сбоев.
