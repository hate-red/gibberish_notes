# Лекция 2. Закон Амдала. Классификация Флинна
## Основные обозначения
Пусть $T$ время выполнения задачи. Время выполнения на $p$ устройствах ($p$ процессорах $p \space ПЭ$) обозначается $T_{p}$.

Предполагается, что на машине с $1 \space ПЭ$ используется самый эффективный алгоритм.

Пусть для $p=2 \quad T_{2}=8$, а для $p=1\quad T_{1}=10$. Это означает что алгоритм для $p=1$ неэффективен. $\frac{T}{2} \ngtr T_{2}$

![parallel_schema.excalidraw](Materials/parallel_schema.excalidraw)

Величина $S_{p}=\frac{T}{T_{p}}$ называется ускорением. $S_{p} \le p$.

Величина $K=\frac{T_{1}}{T}$ доля времени распараллеливаемых вычислений

## Закон Амдала
$\Large S_{p}=\frac{1}{1-K+\frac{K}{p}}$

Работет для идеальных условий.

Паракомпьютер  - идеальный компьютер, который имеет бесконечное число процессоров.

$\text{При} \space p \rightarrow \infty \quad S_{\infty}=\frac{1}{1-K}$.

Пусть $K=0.9$. Тогда $S_{\infty}=10$.
