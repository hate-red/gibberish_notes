# Что это?
Это небольшой репозиторий, где собраны мои (и не только мои) конспекты лекций. Одна папка - один предмет. Внутри файлы в формате markdown (`.md`) и `.pdf`.ф

# Что с этим не так?
Так уж сложилось, что я пишу лекции в Obsidian, но некоторые особенности форматирования не поддерживаются на Github. Например, ссылки. С ними тяжело.

В Obsidian свой формат ссылок, поэтому где-то ссылки могут быть не работающими. Обычно я оставляю ссылки на другие лекции или файлы. Файлы хранятся в отдельной папке, лекции легко найти по названию.
