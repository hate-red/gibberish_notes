# Что это?
Это небольшой репозиторий, где собраны мои (и не только мои) конспекты лекций.

В папке `1 Курс` лекции за первый курс. В остальных папках находятся лекции по предметам 2-го курса (кроме `Obsidian`, она для посвященных).

Чтобы пользоваться больше ничего знать не надо, но есть нюансы (*хо-хо-хо! и тут они есть!*).

# Что с этим не так?
Так уж сложилось, что я пишу лекции в Obsidian, но некоторые особенности форматирования markdown'а, которыми я пользуюсь не поддерживаются на GitHub. О чем я?

Например, ссылки. С ними тяжело. В pdf формате они не работают. В md работают, но не на GitHub (об этом ниже). Обычно я стараюсь давать ссылкам нормальные имена, поэтому можно найти нужную лекцию/файл/картинку по названию. Удачи!

# Если у вас Obsidian
Во-первых, я вас уважаю. 

Во-вторых, для вас есть специальная папка `Obsidian`. Там все написано так, как это пишу я. Можете просто вставить ее к себе в хранилище и все просто будет работать (почти). Пока что простого способа скачать только эту папку я не придумал, но можно так: 

```shell
git clone https://github.com/hate-red/gibberish_notes.git
```

И затем удаляете из этой папки все, кроме той, что `Obsidian` зовется.

В-третьих, для того чтобы все действительно работало (надеюсь) вам нужен плагин под названием `Excalidraw`. С ним у вас будут отображаться картинки и диаграммы. Их еще и менять можно.
