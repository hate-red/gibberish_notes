# Что это?
Это небольшой репозиторий, где собраны мои конспекты лекций. Одна папка - один предмет. 
Внутри файлы в формате markdown (.md) и иногда дополнительные папи и файлы (например, папка Materials в ТРИЗ'е).

# Что с этим не так?
Некоторые особенности форматирования markdown'а в Obsidian'е не поддерживаются на github'е.
О чем я?
### Ссылки. С ними тяжело
В Obsidian'е свой формат ссылок, поэтому иногда ссылки могут быть битыми (не работающими)

### Матемамтика. 
Для нее используется зубодробительный синтаксис и он не всегда нормально отображается. 
Возможно позже я это исправлю.

# Что с этим делать?
Все лекции, что сюда выкладываются пишутся (или редактируются) мной в `Obsidian`'е, 
поэтому, если вы хотите сделать себе жизнь проще и удобнее, скачайте его себе тоже.

Но если не хотите, то вот ряд советов:
- Сломанная ссылка будет отображаться как путь, где # обозначает заголовок в файле (если ссылка на него, а не на сам файл или картинку). Поищите и найдете.
- Для математики можете попробовать онлайн редакторы `latex`'а (синтаксис на котором написаны математические блоки).

# Не важная часть
Если вам несложно и у вас есть аккаунт на github'е, то пожалуйста поставьте звездочку. Все.
